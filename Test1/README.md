# Nexus AI Finance - Mobile Homepage (Test1)

This project is a high-end, mobile-responsive homepage for **Nexus AI Finance**, a next-generation AI fintech company. 

## Folder Structure
- `/Test1`: Contains the full application source code.
- `/Test2`: Reserved for future components or testing.

## Key Features
- **Institutional Design**: Utilizes a deep navy (`#001D47`) and gold (`#D4C4A8`) color palette.
- **AI-Powered Sections**: Includes Hero, Intelligence, Solutions, and Sustainability sections.
- **Micro-interactions**: Subtle animations using `motion`.

## Technical Stack
- React 18+ / Vite / Tailwind CSS 4.0 / Motion / Lucide React
